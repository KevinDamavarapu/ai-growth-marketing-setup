# AI-Assisted SEO Content Production Playbook

This directory contains the completed Standard Operating Procedure (SOP) and supporting analysis developed from the research documented in this repository.

Rather than presenting a collection of isolated SEO recommendations, the playbook synthesizes evidence from multiple industry experts into a structured operational workflow for AI-assisted SEO content production.

The documents are intended to be read in the order listed below.

---

# Documents

| File | Description |
|------|-------------|
| **01_seo_growth_playbook.md** | The primary Standard Operating Procedure (SOP) describing the recommended AI-assisted SEO content production workflow. |
| **02_where_experts_disagree.md** | Analysis of key areas where researched experts recommend different approaches and the reasoning behind the final decisions adopted in the playbook. |
| **03_what_i_rejected.md** | Recommendations identified during the research that were intentionally excluded from the final playbook, together with the reasoning behind those decisions. |
| **04_my_original_ideas.md** | Original workflow ideas developed during the research that were not directly identified in the collected sources. |
| **05_weaknesses_of_this_playbook.md** | Critical evaluation of the playbook, including assumptions, limitations, and areas requiring future validation. |
| **06_who_i_would_not_recommend.md** | Evaluation of which expert methodology was not adopted as the primary reference for this playbook and the reasoning behind that decision. |
| **references.md** | Repository reference index containing supporting research, expert summaries, repository locations, and guidance for locating the original source material. |

---

# Research Methodology

This playbook was developed by synthesizing research collected from ten leading SEO practitioners through LinkedIn posts, YouTube videos, podcast interviews, and other publicly available educational resources.

Every recommendation in the playbook is supported by evidence collected during the research phase. Where experts presented conflicting recommendations, those differences were evaluated using independent judgment and documented within the corresponding analysis documents.

Original source URLs are preserved within the files located in the `research/` directory. The `references.md` document provides a structured index connecting the playbook to the supporting research.

---
